# 06 — Requisitos no funcionales

| Área                     | Requisito                                                                                                                                          | Cómo se cumple                                                                                                                                                        |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Seguridad**            | HTTPS, cookies HttpOnly/SameSite/Secure, CSRF, XSS, SQLi, validación server-side, rate limiting, tokens hasheados y expirables, mínimo privilegio. | Ver [09-security-model](09-security-model.md). Cabeceras en `next.config.ts`; zod en todas las entradas; Prisma parametrizado; `RateLimiter`; `AuthorizationService`. |
| **Privacidad**           | Privacy by design, minimización, defaults mínimos, visibilidad clara.                                                                              | Defaults por tipo de destinatario; Permission Preview; "¿Quién puede ver esto?"; nada sensible en logs ni en cache offline.                                           |
| **Rendimiento**          | Care Pass utilizable en < 2 s en móvil de gama media.                                                                                              | RSC sin JS pesado en `/s/[token]`; consultas indexadas; sin librerías de gráficos.                                                                                    |
| **Disponibilidad**       | Un solo contenedor sin estado + Postgres.                                                                                                          | `output: standalone`, healthcheck `/api/v1/health`, migraciones al arrancar.                                                                                          |
| **Escalabilidad**        | Horizontal en V1.                                                                                                                                  | Sesiones JWT sin estado; el único estado en memoria (rate limit) tiene interfaz para Redis.                                                                           |
| **Mantenibilidad**       | Monolito modular, TypeScript strict, lint, formato, tests.                                                                                         | `src/modules/*` con fronteras; CI con lint/typecheck/test/build.                                                                                                      |
| **Accesibilidad**        | WCAG 2.2 AA razonable.                                                                                                                             | Radix (foco, roles), labels en todos los campos, `tap-target` 44 px, contraste de tokens, `aria-current` en navegación, `role="alert"` en errores.                    |
| **Internacionalización** | es/en desde el inicio; sin strings dispersos.                                                                                                      | next-intl, `messages/*.json`, fechas con `date-fns` por locale.                                                                                                       |
| **Localización**         | México inicial, arquitectura global.                                                                                                               | `country`, `locale`, `timezone`, `regulatoryRegion` en `User`/`Child`/`Institution`.                                                                                  |
| **Observabilidad**       | Logging estructurado; hooks para Sentry/OTel.                                                                                                      | pino con redacción; `instrumentation.ts`.                                                                                                                             |
| **Portabilidad**         | Sin acoplamiento a proveedor cloud.                                                                                                                | Docker; `StorageProvider` (local/S3); `Mailer`; `AIProvider`.                                                                                                         |
| **Retención**            | Preparar expiración/borrado/exportación.                                                                                                           | Soft delete; exportación JSON; políticas por región en V1.                                                                                                            |
| **Trazabilidad**         | Toda operación sensible auditada.                                                                                                                  | `AuditService` append-only; tests verifican eventos.                                                                                                                  |

## Presupuestos y límites del MVP

- Documentos: ≤ 10 MB, PDF/imagen.
- Texto del asistente: ≤ 4 000 caracteres.
- Snapshot de versión: todo el perfil (decenas de items); aceptable para el volumen MVP.
- PIN: 4–6 dígitos, 5 intentos.
- Enlace: 12 h de cookie de PIN/"visto" por dispositivo.
